# Ai_model
Ai-notes-classifier-Handwritten vs Printed Study Material
## Project Summary
Bulit an AI-powered image classifier to automatically sort 12th class study material into handwritten notes and printed resources.This helps in organising digital notes before board exams.
## Problem Statement 
During 12th, we collect 100s of pages - some are our handwritten notes, some are printed modules.Sorting manually wastes time. This AI does it automatically.
